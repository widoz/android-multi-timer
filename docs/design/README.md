# Design

`mockup.html` is the interactive mockup of Multi Timer used to design and approve every UI change before it is built (see [ADR 0002](../adr/0002-mockup-first-workflow.md)). Open it in a browser: timers run live, dialogs, Settings, theme switching and the bundled 8-bit sounds all work. Phone sounds, notifications and background alarms cannot run in a browser and are only described.
