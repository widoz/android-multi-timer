# Multi Timer: developer guide

An Android app for running several countdown timers at once. Each timer is independent:
start, pause, reset, add or remove a minute, edit or delete any of them without affecting the others.
File paths below are relative to the repository root.

- **Edit** reuses the new-timer panel. Label, color and sound change in place; a new duration
  restarts the timer, after a confirmation if it had already counted some time.
- **Delete** asks for confirmation, then offers Undo for a few seconds.
- **Full screen** (four-arrows icon next to start/pause): one timer, large. Other timers that finish
  meanwhile appear in a tray at the bottom, one swipeable card each with Stop and +1 min. The
  screen stays on (Settings › Full screen › Keep screen on, or the sun icon in full screen) and the
  system bars are hidden. See [ADR 0015](adr/0015-full-screen-timer.md).
- **Reorder**: long-press a card (outside its buttons) and drag it; the other cards move aside and a
  shaded layer marks where it lands, and the list scrolls near its edges. Long-press and release in
  place for the Move menu (Move to top / up / down / to bottom); TalkBack offers the same actions on
  each card. The order is the stored list order, so it survives restarts; new timers still go on top.
  Drag state lives in `ui/Reorder.kt`; the repository is updated once, on drop (`TimerRepository.move`).
- **Settings** (gear icon): Theme (System default, Light, Dark), the default alarm sound and Keep screen on.
- **Sounds**: each timer uses the default sound unless you pick its own in the New/Edit panel.
  The picker lists the app's own sounds, then the phone's alarm sounds ("Phone's alarm sound"
  first), then "Silent"; tap one to preview it.
- **App sounds**: five original 8-bit sounds in `app/src/main/res/raw` (Power chime, the default;
  Pixel bell; Beeper; Gentle rise; Jingle). They were synthesized from scratch by
  `tools/make_sounds.py` (Python + numpy, then `ffmpeg -c:a libvorbis -q:a 5`), so they can be
  shipped freely and regenerated or tweaked. Stored as `app:<name>`.
- **Ringing**: `alarm/AlarmService.kt` plays the sound itself on the alarm stream (alarm volume),
  looping until stopped, like a clock app. Notification sounds can be muted by the phone's sound
  mode or Do Not Disturb, so they are not used. One "ringing" notification covers all finished
  timers, with Stop / +1 min (or Stop all).

- **Min Android version:** 11 (API 30). Targets API 35.
  - Android 12: exact alarms use `SCHEDULE_EXACT_ALARM`, which the user can revoke (timers then
    ring a few minutes late). Android 13+ uses `USE_EXACT_ALARM`, granted at install.
  - Android 11–12: no notification permission prompt (notifications are on by default).
  - Android 11: the in-app Theme setting is applied by the app itself; the startup window may
    briefly show the phone's theme. Android 12+ uses per-app night mode.
- **Stack:** Kotlin, Jetpack Compose, Material 3. No third-party libraries.

## Open and run

1. Open the repository folder in Android Studio (Ladybug or newer) with **File › Open**.
2. Let Gradle sync; Studio creates `local.properties` pointing at your Android SDK.
3. Pick an Android 11+ device or emulator and press **Run**.

From the command line, with `ANDROID_HOME` set:

```bash
./gradlew assembleDebug
```

The APK lands in `app/build/outputs/apk/debug/`.

## How it works

Source files are under `app/src/main/java/dev/multitimer/app/`.

| Piece | File | Role |
|---|---|---|
| State | `data/TimerRepository.kt` | Single source of truth. Saves every change to SharedPreferences and updates the alarm, the notification and the alarm service for that timer. |
| Model | `data/TimerItem.kt` | A running timer stores its end time, a paused one stores time left, so nothing drifts. |
| Settings | `data/AppSettings.kt` | Theme choice and the default alarm sound. |
| Alarms | `alarm/AlarmScheduler.kt` | One exact alarm per running timer (`setExactAndAllowWhileIdle`), so timers finish on time even in Doze or with the app closed. |
| Ringing | `alarm/AlarmService.kt` | Foreground service that plays the finished timer's sound on the alarm stream until it is stopped, and shows the ringing notification. |
| Notifications | `alarm/TimerNotifier.kt` | One silent notification per running or paused timer. Running ones use the system countdown chronometer, so no service runs while timers only count down. |
| Sounds | `alarm/Sounds.kt` | App sounds, the phone's alarm sounds (deduplicated by name), titles and the picker preview. |
| Receivers | `alarm/Receivers.kt` | Alarm firing, notification buttons (Pause/Resume, +1 min, Reset/Stop, Stop all) and restoring timers after reboot or app update. |
| Full screen | `ui/FullScreenTimer.kt`, `alarm/FullScreenState.kt` | Full-screen timer, tray of finished timers (pager), keep-screen-on and hidden system bars; tells the alarm service not to pop up notifications while visible. |
| UI | `ui/` | Timer list and cards, quick-start chips, create/edit bottom sheet, Settings, sound picker, confirmation dialogs, Undo snackbar. |

## Release builds

Release builds are signed with the key described in `keystore.properties` at the project root.
That file and the `.jks` key are git-ignored: keep them private and back them up, because updates
only install over an existing copy when signed with the same key.

```bash
./gradlew assembleRelease
```

The signed APK lands in `app/build/outputs/apk/release/app-release.apk`. Without
`keystore.properties`, the release APK is built unsigned. Bump `versionCode` and `versionName` in
`app/build.gradle.kts` for each release.

## Theme and accessibility

- Light is white, dark uses Material's neutral greys (`#121212`, cards `#1E1E1E`). Controls are
  neutral; color is reserved for each timer's color and the orange of a finished timer.
- The Theme setting calls `UiModeManager.setApplicationNightMode` on Android 12+, so the status
  bar, startup window and dialogs follow the choice too (`data/AppSettings.kt`). On Android 11
  `MainActivity` applies it to the Compose theme and system bars.
- Colors meet WCAG 2.2 AA in both themes: text >= 4.5:1, control outlines and timer colors >= 3:1.
  In `ui/theme/Theme.kt`, `outline` is used for every border and line and must stay >= 3:1;
  `outlineVariant` is only the progress-ring track.
- Touch targets are at least 48dp, icon buttons and color swatches have TalkBack labels, and the
  countdown shrinks to fit instead of clipping at large font sizes.

## Permissions

- `POST_NOTIFICATIONS`: asked on first launch (required on Android 13+). Without it timers still run and ring, but cannot show notifications; the app shows a card linking to settings.
- `USE_EXACT_ALARM`: granted at install on Android 13+. Google Play only allows it for apps whose core function is alarms or timers, which this is.
- `SCHEDULE_EXACT_ALARM` (Android 12 only, `maxSdkVersion="32"`): exact alarms on Android 12.
- `FOREGROUND_SERVICE`, `FOREGROUND_SERVICE_SYSTEM_EXEMPTED`: the alarm service that plays the sound while a timer rings.
- `RECEIVE_BOOT_COMPLETED`, `VIBRATE`.

No network permission: the app works fully offline and collects no data.

## Customising

- Package name: `dev.multitimer.app` in `app/build.gradle.kts` (`namespace` and `applicationId`) and the `java/dev/multitimer/app` folder. Change it before publishing.
- Wallpaper-based colors: pass `dynamicColor = true` to `MultiTimerTheme` in `MainActivity.kt`
  (Android 12+, not contrast-checked).
